Paddock

Isolated web hosting

Paddock is a hosting panel that runs PHP sites in vhosts that cannot see or touch each other's files or processes. Owners manage several vhosts within limits set by an admin.

How vhosts are kept apart

One user per vhost

Each vhost runs as its own Linux user, with its own sandboxed Apache and PHP-FPM under systemd.

Private files

A vhost sees only its own tree; other vhosts' files, sockets and processes are hidden from it.

Firewalled backends

Only the front Apache may reach a vhost's backend; tenants cannot connect to each other.

Fair limits

Owner and vhost slices cap CPU, memory and tasks; XFS project quotas cap disk.

Jailed access

SFTP accounts, which SCP clients use too, land in a chroot holding only their own vhost. No shell access.

Guarded admin

A root agent makes every host change and requires a fresh TOTP code for admin actions.

Install

On a fresh AlmaLinux 9.4+ server with SELinux enforcing and a spare disk for /srv/www (or --www-file 20G to use a disk image instead), fetch the bootstrap script of a release, check it, and run it:

VER=@VERSION@
BASE=https://github.com/@REPOSITORY@/releases/download/$VER
curl -fsSLO $BASE/bootstrap.sh
curl -fsSLO $BASE/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
sudo bash bootstrap.sh --hostname panel.example.com --www-device /dev/vdb --format

The script prepares the host, installs the paddock RPM from the repository below, and prints the first admin's credentials once. The panel then listens on port 8443. The install guide covers requirements, options, first steps, upgrades and troubleshooting.
