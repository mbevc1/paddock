Managing admins

Admins are managed as root on the server, never from the panel, so a compromised panel cannot create or change one.

paddock admin add NAME
paddock admin disable NAME
paddock admin enable NAME
paddock admin remove NAME
paddock admin reset-password NAME
paddock admin totp-reset NAME
paddock admin login-totp-off NAME
paddock admin unlock -for 8h NAME
